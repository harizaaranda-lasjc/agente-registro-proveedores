# Agente de Registro de Proveedores — Periferia IT Group

Solución desarrollada para el reto técnico de **Periferia IT Group S.A.S. (Equipo Perxia 2.0)**. Consiste en un agente conversacional inteligente que automatiza la lectura, el mapeo de datos maestro, la generación de formularios y la preparación de paquetes de soporte para el registro de proveedores.

---

## 🛠️ Requisitos Previos

- **[Bun](https://bun.sh)** (v1.0.0 o superior)
- **Git**
